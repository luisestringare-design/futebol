## 📖 Sobre o Projeto

O **SoccerStats** nasceu da paixão por futebol e dados. O objetivo principal é centralizar informações sobre campeonatos, times, jogadores e partidas, oferecendo gráficos intuitivos para analistas de desempenho, torcedores e entusiastas do esporte Bretão.

> **Nota:** Este projeto consome dados históricos e em tempo real para gerar insights sobre probabilidades de vitórias, posse de bola e mapas de calor de jogadores.

---

## ✨ Funcionalidades

* **Placar ao Vivo:** Acompanhamento em tempo real dos principais campeonatos (Brasileirão, Champions League, Premier League).
* **Perfil do Jogador:** Estatísticas detalhadas (gols, assistências, passes certos, cartões e quilômetros percorridos).
* **Comparador de Times:** Ferramenta gráfica para confrontar o desempenho de duas equipes na temporada.
* **Simulador de Tabela:** Algoritmo preditivo que projeta a classificação final com base nos próximos jogos.

---

## 🚀 Tecnologias Utilizadas

O ecossistema do projeto foi construído com as seguintes ferramentas:

* **Frontend:** React.js / Tailwind CSS / Chart.js
* **Backend:** Node.js / TypeScript / Express
* **Banco de Dados:** PostgreSQL / Redis (Cache de placares ao vivo)
* **API de Dados:** API-Football
